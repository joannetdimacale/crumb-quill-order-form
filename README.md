# Crumb & Quill Order Form

Static custom order form for GitHub Pages, connected to Formspree.

## Files
- `index.html`
- `styles.css`
- `script.js`

## Formspree
Current endpoint: https://formspree.io/f/xojzvzdn

The endpoint is already placed in `script.js`.

## GitHub Pages setup
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to Settings → Pages.
4. Source: Deploy from a branch.
5. Branch: `main` / root.
6. Save.
7. Wait for GitHub to publish the link.

## Edit products/prices
Open `script.js` and edit the `products` array.
